# 07 モデルケース・シリーズの作り方 ― 「こういうやり方もある」を、数字で語る

> **2026-10-17 方針変更（最優先）**: 本人は「50万円の戸建てを1戸ずつ買って積み上げる」投資を実際にはしていない（別のやり方で成果を出している）。
> 動画・SNS の物件・数字・失敗談は、**本人の体験ではなく「こういう投資のやり方もある」というモデルケース（説明のための例）**として語る。
> コツさんは「モデルケースを案内する大家キャラ」で、本人とイコールではない。「私が買った」「私の家」「私が損した」「私の場合」と言い切らない。
> この文書の中に「実例」「本人の数字」「私の場合」とある箇所は、「モデルケース」「この例では」と読み替える。


YouTube は「夢を見せる（自分にもできると思わせる）」、note は「やり方（ノウハウ）」。
この文書は YouTube 側のモデルケース・シリーズの決まり（ファイル名は旧称の「実例シリーズ」のまま）。

## 1. 語り手と立場

- 答え手＝コツさん（モデルケースを案内する大家キャラ。本人の体験として語らない）。聞き手＝ぽん太（視聴者の疑問を言う役）。
- 冒頭の自己紹介は固定文:
  「不動産の仕入れと販売を仕事にしている大家、コツさんです。数字は説明のためのモデルケースです」
  （本人は法人で大家業もしているが、やり方は戸建ての積み上げとは別。戸建てを買っているとは言わない）
- 社名（ジョージ・アセット等）、宅建業者の免許番号、屋号は言わない。

## 2. 特定を避ける線（守る）

| 項目 | 出してよい | 出さない |
|---|---|---|
| 場所 | 都道府県、区・市（例: 東京都板橋区） | 町名、丁目、駅名、路線、最寄り施設 |
| 物件 | 築年の概数（築50年前後）、構造（木造）、戸建て／アパートの別 | 外観が分かる写真、間取り図そのもの、登記情報、地番 |
| 写真 | 室内の部分（床・水回り・壁）で、窓の外や表札・隣家が写らないもの | 外観、玄関、表札、郵便物、周辺の風景 |
| 数字 | 相場に沿った丸めた数字（50万・150万・7万）。モデルケースと明示 | 端数まで、特定の物件を思わせる数字 |
| 時期 | 「○年目」「数年前」 | 年月日 |
| 相手 | 「売主」「仲介」「職人」 | 会社名、人名 |

迷ったら「出さない」。1 本の動画の情報を全部足しても、物件が 1 つに絞れないこと。

## 3. 表現の線（宅建業者として）

- 使わない言葉: 簡単、誰でも、確実、必ず、ほったらかし、不労所得（「家賃収入」と言う）。
- 利回りを言うときは「表面」と明示し、同じ画面か直後に経費と手残りを出す。
- 「モデルケース」「説明のための例」を冒頭 15 秒以内に 1 回は台詞で言う。常設の注記（disclaimer）にも書く。体験談のように「私が〜した」と言い切らない。
- 写真は「イメージ写真」と画面に書く。AI で作った写真を使う回は、アップロード時に「改変または合成コンテンツ」に該当するかを確認する（リアルな写真に見えるものは原則チェック）。
- 他人に勧める言い方をしない。「〜してください」は「今日の一歩」の行動（眺める・調べる・書く）だけ。
- 個別相談・物件紹介は受けない旨を説明欄に毎回。
- 仲介手数料は法令どおりに言う。800 万円以下の家・土地（売買・交換）は、2024 年 7 月から上限が 30 万円＋税＝税込 33 万円（売主・買主それぞれ）。
  上限であって定額ではない（媒介契約の前に説明・書面で合意）。モデルケースの諸費用は上限で計算する（docs/15 §6.1）。

## 4. 1 本の型（長尺 5〜8 分）

1. **数字のフック**（counter）: 買値 → 家賃 → 積み上げた先の数字。
2. **自己紹介の固定文**（title）。
3. **第 1 章 本当にあるのか／どこで見つけたか**（list ＋ photo）。
4. **第 2 章 1 戸の数字と積み上げ**（flow の数式 → portfolio → timeline）。数字は必ず「買値 → 直し → 家賃 → 経費 → 手残り」の順。
5. **第 3 章 うまくいかなかったこと**（compare）。失敗 2 つと、防げた確認。
6. **まとめ → 今日の一歩 → note**。

## 5. 公開前の確認表（★印の数字を本人が直す）

台本の `★` が付いた箇所は、公開前に本人が次を確認する。★ は画面にも字幕にも出ない（仕組みが自動で消す）ので、台本に残したままでよい。

- [ ] 買値・直し・家賃は、実態を丸めた数字になっているか（盛っていないか）
- [ ] 戸数・年数は実態の範囲内か（「見えてきます」「計算です」の言い方になっているか）
- [ ] 区・市より細かい場所が入っていないか
- [ ] 写真に外観・表札・窓の外が写っていないか
- [ ] 失敗談の金額は実態に近いか
- [ ] 「簡単」「誰でも」「確実」が入っていないか（検索して確認）

## 6. 写真の入れ方

`photo` レイアウトの `image:` に、台本ファイルからの相対パスで指定する（例: `image: photos/002_before.jpg`）。
写真は `youtube/scripts/photos/` に置き、Git には入れない（.gitignore 済み）。
写真が無いあいだは枠だけ表示されるので、先に台本と音声を作って、写真はあとから差し替えてよい。
