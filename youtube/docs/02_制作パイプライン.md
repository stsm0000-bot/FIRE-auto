# 02 制作パイプライン ― 台本 1 ファイルから動画・サムネ・説明文まで

## 流れ

```
scripts/NNN_題名.yaml
   │
   ▼  python pipeline/make_video.py build scripts/NNN_題名.yaml --out out/NNN
[1] スライド描画   台本の場面×段階ごとに HTML を組み、Chrome のヘッドレスで PNG に（1920×1080 / 1080×1920）
[2] 音声           台詞ごとに VOICEVOX（http://127.0.0.1:50021）で wav。台詞の後に 0.3 秒、場面の後に 0.6 秒の間
[3] 字幕           台詞の開始・終了時刻から ASS を生成（話者色、自前の折り返し）
[4] 画の並び       台詞の長さ＝画の表示秒。画が変わる所は 6 コマのクロスフェード画像を挟む
[5] ffmpeg         4％拡大＋遅い揺れ → 進捗バー → 字幕焼き込み → H.264 CRF18
                   音: BGM をサイドチェーンで下げて混合 → ラウドネス 2 パス正規化（-14 LUFS）→ AAC 192k
[6] QA             解像度・尺・ラウドネス・最大無音を検査し qa.json に
[7] 公開用メモ     publish.md（タイトル・説明文・目次タイムスタンプ・タグ）と thumb.png
```

出力フォルダ `out/NNN/` には `NNN.mp4`, `thumb_*.png`, `publish.md`, `qa.json`, `work/`（中間ファイル）が入ります。
`work/` は再実行時のキャッシュです。台詞や画を直してもう一度 build すると、変わった所だけ作り直します。

## 必要なもの（デスクトップ側）

| もの | 用途 | 入れ方 |
|---|---|---|
| Python 3.10 以上 | 本体 | python.org |
| pyyaml, Pillow | 台本読み込み・画像 | `pip install -r pipeline/requirements.txt` |
| ffmpeg（libx264, libass 入り） | 結合 | gyan.dev の full ビルドを展開し PATH に通す |
| Google Chrome または Edge | スライド描画 | 既にある（見つからなければ環境変数 `CHROME_PATH`） |
| VOICEVOX | 音声 | VOICEVOX を起動しておく（エンジンが 50021 番で待つ）。別の場所なら `VOICEVOX_URL` |
| 日本語フォント | 画と字幕 | Windows は BIZ UDPゴシック（既定）。台本の `font:` で変更可 |
| BGM | 音 | `pipeline/assets/bgm.mp3` に置く（YouTube オーディオライブラリ、帰属表示不要のもの） |

VOICEVOX の話者 ID は台本の `speakers` で上書きできます。既定は 冥鳴ひまり＝14、雀松朱司＝52 です。
**初回は `http://127.0.0.1:50021/speakers` を開いて ID を確認してください**（版によって番号が変わります）。

## コマンド

```bat
cd C:\Users\stsm0\Desktop\FIRE-auto\youtube
python pipeline\make_video.py build scripts\001_資料が届かない人.yaml --out out\001
python pipeline\make_video.py build scripts\S001_最初の一通は4つ.yaml --out out\S001
python pipeline\make_video.py build scripts\001_資料が届かない人.yaml --out out\001 --tts stub   # 音声なしで画と尺だけ先に見る
python pipeline\make_video.py qa out\001\001.mp4                                            # 検査だけ
```

オプション: `--bgm ファイル`（既定 pipeline/assets/bgm.mp3）、`--bgm-db -22`（BGM の音量）。

## QA の合格基準

| 項目 | 基準 |
|---|---|
| 解像度 | 長尺 1920×1080、ショート 1080×1920 |
| 尺 | 長尺 4〜10 分、ショート 20〜59 秒 |
| 統合ラウドネス | -15.5〜-12.5 LUFS |
| 最大無音 | 1.2 秒以下 |

不合格の動画は公開しません。尺が短いときは台本を足す、長いときは章を削る。無音が長いときは `pause` を見直す。

## この環境（クラウド）で検証済みのこと

- Chrome ヘッドレスでの日本語描画、ASS 字幕の焼き込み、クロスフェード、進捗バー、BGM のサイドチェーン、
  2 パスのラウドネス正規化、QA、publish.md・サムネ生成。すべてスタブ音声（無音）で mp4 まで通した。
- 長尺（12 場面・40 台詞）は 4 コアで約 2 分で完成。ショートは約 20 秒。
- **検証していないこと**: VOICEVOX の実接続（この環境では起動できない）。デスクトップで最初に試すのはここ。

## 仕組みを変えたいとき

- 見た目: `pipeline/templates/slide.html` の CSS（色は `:root` の変数）。
- サムネ: `pipeline/templates/thumb.html`。
- 間の長さ・クロスフェード・字幕の文字数: `make_video.py` 冒頭の定数。
- レイアウトの追加: `render_body()` に分岐を足し、CSS を足す。
