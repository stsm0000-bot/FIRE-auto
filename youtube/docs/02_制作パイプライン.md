# 02 制作パイプライン ― 台本 1 ファイルから動画・サムネ・説明文まで

## 流れ

```
scripts/NNN_題名.yaml
   │
   ▼  python pipeline/make_video.py build scripts/NNN_題名.yaml --out out/NNN
[1] スライド描画   台本の場面×段階ごとに HTML を組む。状態が変わる台詞では node+Playwright で動き（出現・数字が伸びる・
                   戸建てが増える）を 1 コマずつ PNG に（0.5〜2.4 秒ぶん）。残りは最後のコマで保持。
                   node が無いときは Chrome のヘッドレスで最終状態だけ撮る（動きなし）
[2] 音声           台詞ごとに VOICEVOX（http://127.0.0.1:50021）で wav。話者・スタイル（喜び・熱血など）は台本で指定。
                   話速 1.1・抑揚 1.3 が既定（棒読み対策）。台詞の後に 0.3 秒、場面の後に 0.6 秒の間
[2'] 効果音          要素が出る「ポン」、数字が伸びる「コイン」、合計・締めの「キラン」、章扉の「ディン」を自前合成して配置
[2''] 話者アイコン    聞き手・大家のアイコンを画面下に常設し、話している側が揺れて光る（ffmpeg のオーバーレイ）
[3] 字幕           台詞の開始・終了時刻から ASS を生成（話者色、自前の折り返し）
[4] 画の並び       台詞の長さ＝画の表示秒。画が変わる所は 6 コマのクロスフェード画像を挟む
[5] ffmpeg         4％拡大＋遅い揺れ → 進捗バー → 字幕焼き込み → H.264 CRF18
                   音: BGM（指定が無ければ自前合成の明るいループ）をサイドチェーンで下げ、効果音と混合 → ラウドネス 2 パス正規化（-14 LUFS）→ AAC 192k
                   章扉への切り替えはオレンジの斜めワイプ、それ以外はクロスフェード
[6] QA             解像度・尺・ラウドネス・最大無音を検査し qa.json に
[7] 公開用メモ     publish.md（タイトル・説明文・目次タイムスタンプ・タグ）と thumb.png
```

出力フォルダ `out/NNN/` には `NNN.mp4`, `thumb_*.png`, `publish.md`, `qa.json`, `work/`（中間ファイル）が入ります。
`work/` は再実行時のキャッシュです。台詞や画を直してもう一度 build すると、変わった所だけ作り直します。

## 必要なもの（デスクトップ側）

| もの | 用途 | 入れ方 |
|---|---|---|
| Python 3.10 以上 | 本体 | python.org |
| pyyaml, Pillow | 台本読み込み・画像 | `pip install -r pipeline/requirements.txt` |
| ffmpeg（libx264, libass 入り） | 結合 | gyan.dev の full ビルドを展開し PATH に通す |
| Google Chrome または Edge | サムネ・静止画の描画 | 既にある（見つからなければ環境変数 `CHROME_PATH`） |
| node.js ＋ playwright | 動きのコマ撮り | nodejs.org で node を入れ、`youtube/pipeline` で `npm init -y && npm i playwright`。実行時 `set PW_CHANNEL=chrome` で手元の Chrome を使う。無ければ静止画で動く（`MOTION=0`） |
| VOICEVOX | 音声 | Windows は公式アプリ（voicevox.hiroshiba.jp）を起動しておくだけ（エンジンが 50021 番で待つ）。別の場所なら `VOICEVOX_URL`。Linux は engine の 7z を展開して `./run --host 127.0.0.1` |
| 日本語フォント | 画と字幕 | Windows は BIZ UDPゴシック（既定）。台本の `font:` で変更可 |
| BGM | 音 | 無ければ自前合成の明るいループ（権利問題なし）。差し替えるなら `pipeline/assets/bgm.mp3`（YouTube オーディオライブラリの帰属表示不要曲、または Tanner Helland の CC BY 4.0 曲＝台本の `bgm_credit:` にクレジット） |
| node.js ＋ playwright | 動きのコマ撮り | nodejs.org で node を入れ、`youtube/pipeline` で `npm init -y && npm i playwright`。実行時 `set PW_CHANNEL=chrome`。無ければ静止画で動く（`MOTION=0`） |

話者は台本の `speakers` で、話者名とスタイル名で指定します（id は仕組みが /speakers から引く）。既定は 聞き手＝ずんだもん（ノーマル）、大家＝青山龍星（ノーマル）。
台詞ごとに `st: 喜び` のようにスタイルを変えられます（青山龍星: ノーマル／熱血／不機嫌／喜び／しっとり／かなしみ／囁き、ずんだもん: ノーマル／あまあま／ツンツン／セクシー／ささやき／ヒソヒソ／ヘロヘロ／なみだめ）。
旧来の `voicevox_id:` 指定も使えます。

## コマンド

```bat
cd C:\Users\stsm0\Desktop\FIRE-auto\youtube
python pipeline\make_video.py build scripts\001_資料が届かない人.yaml --out out\001
python pipeline\make_video.py build scripts\S001_最初の一通は4つ.yaml --out out\S001
python pipeline\make_video.py build scripts\001_資料が届かない人.yaml --out out\001 --tts stub   # 音声なしで画と尺だけ先に見る
python pipeline\make_video.py qa out\001\001.mp4                                            # 検査だけ
```

オプション: `--bgm ファイル`（既定 pipeline/assets/bgm.mp3）、`--bgm-db -22`（BGM の音量）。
環境変数: `PW_CHANNEL=chrome`（Playwright に手元の Chrome を使わせる）、`MOTION=0`（動きなし）、`CHROME_PATH`、`VOICEVOX_URL`。

## QA の合格基準

| 項目 | 基準 |
|---|---|
| 解像度 | 長尺 1920×1080、ショート 1080×1920 |
| 尺 | 長尺 4〜10 分、ショート 20〜59 秒 |
| 統合ラウドネス | -15.5〜-12.5 LUFS |
| 最大無音 | 1.2 秒以下 |

不合格の動画は公開しません。尺が短いときは台本を足す、長いときは章を削る。無音が長いときは `pause` を見直す。

## 音の設計（棒読みにしないために）

- 話速 1.1、抑揚 1.3 を既定に（台本の `voice:` で変更）。台詞は 1 つ 40 文字以内で、驚き・合いの手を聞き手に言わせる。
- 感情の付け方: 数字を出す所は「喜び」、失敗談は「しっとり」、言い切りは「熱血」。聞き手の疑いは「ツンツン」、驚きは「あまあま」。
- 効果音は -10 dB（`sfx_db:` で変更）、BGM は -22 dB（`--bgm-db`）。声が鳴っている間は BGM が自動で下がる。
- アイコンを出さない場合は台本に `avatars: false`、効果音を切るなら `sfx: false`。

## この環境（クラウド）で検証済みのこと

- Chrome ヘッドレスでの日本語描画、ASS 字幕の焼き込み、クロスフェード、進捗バー、BGM のサイドチェーン、
  2 パスのラウドネス正規化、QA、publish.md・サムネ生成。すべてスタブ音声（無音）で mp4 まで通した。
- 動きあり・本番音声: 長尺（15 場面・50 台詞）は 4 コアで約 8 分（音声合成 2 分＋コマ撮り 4 分＋結合 2 分）。ショートは約 70 秒。
- VOICEVOX エンジン 0.25.2（Linux CPU 版）をこの環境で起動し、本番音声で長尺・ショートとも生成・QA 合格を確認済み。

## 仕組みを変えたいとき

- 見た目: `pipeline/templates/slide.html` の CSS（色は `:root` の変数）。
- サムネ: `pipeline/templates/thumb.html`。
- 間の長さ・クロスフェード・字幕の文字数: `make_video.py` 冒頭の定数。
- レイアウトの追加: `render_body()` に分岐を足し、CSS を足す。
