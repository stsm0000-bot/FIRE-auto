# 16 動画 1 本の作り方 ― 毎回くり返す型（v7）

2026-10-18 版。002（50万円の家を家賃7万円で貸すやり方）で固めた作り方を、**毎回同じ手順で回せる型**にしたもの。
デスクトップの Claude Code は、新しい動画を作るときにこの文書の §1〜§8 を上から順に進める（`/make-video` でも同じ流れになる）。

役割: **本人**＝題材を選ぶ・★の数字を確かめる・アップロードと投稿のボタンを押す。**Claude Code**＝それ以外（台本・ビルド・検査・投稿文・段取りの案内）。

## 1. 題材とタイトルを決める

- 候補は docs/15 §9.2（次の 4 本）と docs/13（題材 20）から。前回の動画の**次回予告と同じ題**を最優先にする。
- 型は 3 つのどれか: **よくある失敗**（数字が膨らむ・空室）／**反論への回答**（再建築不可・管理できるのか）／**数字の分解**（管理費・修繕・空室で手残りはいくら減る）。
- **探し方そのものを動画の主題にしない**（探し方・買い方・業者から紹介してもらうやり方は note の役目。動画からは note へ送る）。
- タイトルは 28 字以内。「数字＋結果」＋「｜失敗○つ込み」「｜モデルケース」など（docs/13 §3）。Claude が 3 案出し、本人が選ぶ。
- サムネの文字は 2 行・10 字以内で数字を入れる。キャラは既定でユイさん、驚きの回はソウタの surprised。

## 2. 台本を書く

1. ひな形をコピーする。
   ```bat
   copy scripts\_ひな形_長尺.yaml scripts\003_題名.yaml
   copy scripts\_ひな形_ショート.yaml scripts\S005_題名.yaml
   ```
2. ○○ を埋める。**ひな形は骨組み（約 2 分）**なので、002 と同じく **35 場面・台詞 140 本前後（約 10 分）**まで肉付けする。002 の台本（`scripts/002_50万円の戸建てから.yaml`）が完成見本。
3. 守ること（毎回。ひな形の冒頭にも書いてある）:
   - **モデルケース**として語る。本人の体験として言い切らない。名乗りは固定文「不動産の仕入れと販売を仕事にしている大家、ユイです」。
   - 禁止語: 簡単・誰でも・確実・必ず・不労所得・儲かる。場所は区・市まで。社名・丁目・駅名なし。個別相談を誘わない。
   - **経費は管理費込み**（家賃の 3〜5.5％）。「諸経費 約○万円」と丸めてよい。利回りは「表面」と言い、すぐ手残りを出す。
   - **仲介手数料は法令どおり**（800 万円以下は上限 税込 33 万円。上限で定額ではない）。
   - **ポータルサイトで探そう、地元の家をコメントで、は言わない。** note へ 2 回送る（中盤の「どうやって見つけるの？」と締め）。締めの `label` は「続きは note で」。
   - 写真を使う回は「イメージ写真」と出す（`scripts/photos/`）。
4. 画面の決まり:
   - 物語の場面（`layout: scene`）と図解（list・flow・compare・bar・timeline・counter・quote）を**交互に**。語彙は docs/12。
   - **1 台詞 8 秒以内**（約 45 字まで）。**同じ画が 8 秒を超えない**ように `step`・`mark` を進める。
   - 札（price・sign）が顔にかかるときは `x:` と `x_fixed: true` で位置を決める。ショートの見出しは 12 字くらいまで。
   - 一覧（list）は 4 行まで（5 行以上は分ける）。
5. ショート 3 本は長尺から切り出す（数字・失敗・確認の仕方）。59 秒以内。
6. 冒頭コメントの **★ に、本人に確かめる数字**を並べる（台詞には ★ を入れない）。

## 3. 音声なしで試す（速い）

```bat
cd C:\Users\stsm0\Desktop\FIRE-auto\youtube
set PW_CHANNEL=chrome
python pipeline\make_all.py scripts\003_題名.yaml scripts\S005_題名.yaml scripts\S006_題名.yaml scripts\S007_題名.yaml --tts stub
```

- 尺の見積り（長尺 9 分 30 秒〜10 分 30 秒、ショート 59 秒以内）と「同じ画が 8 秒超」を見る。
- `out\003\work\` のコマや mp4 を開いて、札の重なり・改行の崩れを見る。崩れていたら台本を直してもう一度。

## 4. ★の数字を本人に確かめる

- Claude は ★ の一覧を**チェックボックス形式**で本人に出す（「★2 は 150→200 に」のように番号で答えてもらう）。
- 確かめるのは「相場として無理がないか」だけ（本人の実績である必要はない。docs/15 §6）。

## 5. 本番のビルド

```bat
rem VOICEVOX を起動しておく（http://127.0.0.1:50021/version が開けば OK）
python pipeline\make_all.py scripts\003_題名.yaml scripts\S005_題名.yaml scripts\S006_題名.yaml scripts\S007_題名.yaml
```

- できるもの: `out\<id>\納品\` に **mp4・サムネ.png・投稿文\・publish.md・字幕の時刻.txt** がそろう。
- QA の合格基準: 解像度、尺、ラウドネス -14 LUFS 前後、無音 1.2 秒以下、同じ画が 8 秒以内、画と音の差 0.1 秒以内。
- **投稿文の時刻合わせ**: `字幕の時刻.txt` で山場の時刻を見て、台本の `sns:`（x_thread の最後・x_single・community_quiz の answer_in）を直し、もう一度 `make_all.py`（音声と画は作り直さないので速い）。
- 不合格のときの直し方は §9。

## 6. 本人が見て OK を出す

- Claude は mp4 とコマ一覧（`out\<id>\納品\`）を本人に渡し、見てほしい時刻（数字の山・note の送客・締め）を添える。
- 直しが出たら 2 に戻る。OK が出たら台本をコミット・プッシュする（ブランチ `claude/fervent-edison-ffigc4`）。

## 7. アップロードと予約（本人が YouTube Studio で）

Claude は `publish.md` と `投稿文\checklist.md` を見せながら、次を 1 つずつ案内する。

1. 動画をアップロード → タイトル・説明欄（`投稿文\youtube_description.txt` をそのまま貼る）・タグ（publish.md）。
2. サムネ（`サムネ.png`）。
3. **「改変または合成コンテンツ」**: AI で作ったリアルな写真を使った回は「はい」。
4. 再生リスト「1戸目の数字」に入れる。終了画面は「次の動画」＋「登録」。
5. 公開設定は**予約**（土曜 7:00）。URL が決まったら台本の `youtube_url:` に書き、`make_all.py` をもう一度（投稿文の動画 URL が埋まる）。
6. ショート 3 本は日・月・水の 7:30 に予約。関連動画に長尺を指定。

## 8. SNS の投稿と 48 時間の対応

`投稿文\checklist.md` が時刻つきの手順（前日 21:00 のコミュニティのクイズ → 公開日 7:05 固定コメント → 7:30 X 単発・Threads → 12:15 X スレッド → 翌日以降）。

- Threads は**手動の返信が主役**（本人の実績: 2026-10-17 に返信対応でプロフィール閲覧 1 日 1.6 万。docs/14 §3.2.1）。伸びている不動産・お金の投稿に、数字 1 つ＋学び 1 行の返信を 1 日 5〜10 件。
- note の記事 URL が決まったら台本の `sns.note_url` を置き換えて `make_all.py` をもう一度。
- コメントには 48 時間、全部返す。

## 9. 困ったとき（よく出るもの）

| 症状 | 直し方 |
|---|---|
| 「同じ画が 8 秒超」 | その場面の台詞に `step` か `mark` を足す。長い台詞を 2 つに割る。最後の台詞を次の場面の頭へ移す |
| 長尺が 11 分を超える／ショートが 59 秒を超える | 台詞を削る・短くする（1 台詞 45 字まで）。声の速さは変えない |
| 札が顔に重なる | 札に `x:`（0〜100）と `x_fixed: true` |
| 見出しが変な所で改行 | 文字を短くする、`\n` で改行位置を決める |
| 一覧が下の断り書きに重なる | 4 行までにする |
| 「話者に スタイル ○○ はありません」 | 台本の `speakers.答.style_map` が抜けている（ひな形からコピー） |
| ディスクがいっぱい | `out\` の古い回の `work\` フォルダを消す（mp4 と納品は残す） |
| VOICEVOX が起動していない | アプリを起動。音声なしで試すなら `--tts stub` |
| 投稿文の警告 | `投稿文\checklist.md` の末尾に理由（禁止語・文字数・URL の位置・時刻表現） |
