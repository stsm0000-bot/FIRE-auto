## 6. 任意: AI 生成クリップ（参考動画の方法）を使うなら

- 参考動画は Claude Code から Higgsfield（MCP）で数秒の 2D アニメを生成して並べる方法。有料（クレジット制）で、商用利用の条件はプランで違うので、使う前に規約を確認する。
- うちの仕組みでは、生成した mp4 を `youtube/scripts/clips/` に置き、台本に
  `- {id: clip1, layout: clip, file: clips/house.mp4, headline: "これが50万円の家", lines: [...]}` と書けば、台詞の長さだけ再生して、問いのピル・テロップ・注記を重ねる。
- 使いどころは「ボロ家の外観」「室内のビフォー」「工事中」の 3 か所まで。残りは自前の物語シーンで足りる。毎回全部を AI 生成にすると絵柄がばらつき、費用も時間もかかる。

## 7. 困ったとき

| 症状 | 見る所 |
|---|---|
| `layout: scene を使うには pipeline/scenes.py が必要です` | pipeline/scenes.py があるか（git pull） |
| 物語シーンでキャラが出ない・位置がおかしい | 台本の `who` が speakers の name（ぽん太／コツさん）と一致しているか。`at` と `act` が docs/12 の語彙か |
| 口パクが動かない | work/slides に `_c_`, `_o_`, `_b_` の 3 枚があるか。`MOTION=0` でも口パクは動く（静止画 3 枚の差し替え） |
| 環境音がうるさい・小さい | 台本の `amb_db:`（既定 0）。効果音は `sfx_db:`（既定 -10）、BGM は `--bgm-db`（既定 -22） |
| clip の映像が「ここに映像」の枠になる | `file:` のパス（台本からの相対）。警告に出たファイル名を確認 |
| Chrome/Edge が見つからない | 環境変数 `CHROME_PATH` |
| 動きが全部静止画 | `node -e "require('playwright')"` が通るか。`PW_CHANNEL=chrome` |
| 字幕が豆腐 | ffmpeg が libass 入りか、台本の `font:`（Meiryo など） |
| 音声が作れない | VOICEVOX が起動しているか、`VOICEVOX_URL`、話者名とスタイル名 |
| 投稿文の警告 | make_posts.py の出力。禁止語・文字数・URL の位置。`--strict` を外せば警告だけで生成する |
