note の記事を「元」にし、動画はその要約と入口にする。順番は、視聴者の段取り（探す前 → 探す → 問い合わせる → 資料を見る → 買う前）に沿う。

## 台本を書く順番（クラウド側の仕事）

1. 002 から順に、長尺 YAML → ショート 2 本の YAML。
2. 各台本はスタブ音声で build して、尺（長尺 4 分以上）と画を確認してからコミット。
3. 1 本ごとに `docs/01` §7 の 5 項目（図が毎回ちがう／具体的な例文／見解／反論への答え／note 対応）を満たしているか見る。

## ネタの作り方（note の記事がまだない話題のとき）

- 記事を先に note に書く → その要約を動画にする、の順を崩さない。動画だけ先に出すと、説明欄の導線が空になる。
- 1 本の記事から動画にする範囲は「3 章ぶん」まで。記事が長ければ 2 本に分ける。
