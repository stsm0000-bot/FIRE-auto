# 12 物語シーン（layout: scene）の書き方 ― 台本部・演出部・統合部の共通仕様

参考動画（Claude Code ＋ 画像生成で「台本と音声から 2D アニメを作る」型）に寄せるため、
図解スライドに加えて **キャラが場所に立って動く「物語シーン」** を入れる。
図解（flow / counter / portfolio …）は数字を見せる場面、物語シーンは「出来事」を見せる場面に使う。

- 台本部: この仕様の語彙だけを使って YAML を書く（ここに無い値は使わない）
- 演出部: `pipeline/scenes.py` と `characters.py`（ポーズ）、`templates/slide.html`（scene の CSS）で、この語彙を**全部**実装する
- 統合部: `make_video.py` の `scene` レイアウト対応、口パク差し替え、効果音・環境音の割当

## 1. YAML の形

```yaml
- id: s_street            # 場面 ID（英数字）
  layout: scene
  bg: street              # 背景（§2）
  time: day               # day / evening / night（省略時 day）
  weather: sun            # sun / cloud / rain（省略時 sun）
  camera: in              # still / in / out / pan_left / pan_right / shake（省略時 still。最初の 1.3 秒だけ動く）
  chars:                  # 画面に出すキャラ（0〜2 人）
    - {who: ぽん太, at: left,  act: walk,  face: normal}
    - {who: コツさん, at: right, act: stand, face: happy}
  props:                  # 小道具（§4）。step で出す順番を決める。step 省略は 1
    - {kind: headline, text: "買値50万円", step: 1}
    - {kind: price,    text: "50万円",   at: center, step: 2}
    - {kind: bubble,   text: "安っ！",   who: ぽん太, step: 3}
  steps: 3                # 省略時は props の最大 step（props が無ければ 1）
  lines:
    - {sp: 聞, text: "…", step: 1, st: "あまあま", face: surprised}
```

- `lines` の `sp` が話している側のキャラは、**その台詞の間だけ口が動き**、`face`（無ければ st から推定）の表情になる。
  話していない側は `chars[].face` の表情で立つ。
- `who` は speakers の `name`（ぽん太 / コツさん）。
- 同じ場面で台詞ごとに画を変えたいときは props の step を増やす（「1 台詞 1 変化」の原則）。
- 場面の切り替えは統合部がクロスフェードする。背景が変わるときは必ず `id` を変える。

## 2. 背景 `bg`（13 種・固定）

| bg | 何の場所 | 使いどころ |
|---|---|---|
| `street` | 住宅街の道（電柱・家並み・空） | 物件を探して歩く、現地へ行く |
| `house_old` | ボロ戸建ての外観（雑草・傾いた塀・割れた窓・錆びたトタン） | 「これが 50 万円の家」 |
| `house_new` | 直した後の外観（きれいな壁・ポスト・花） | ビフォー→アフター、入居 |
| `room_old` | 室内ビフォー（破れた畳・黄ばんだ壁・残置物） | 内見、直す前 |
| `room_new` | 室内アフター（白い壁・床・カーテン・照明） | 直した後、入居者目線 |
| `office` | 不動産屋のカウンター（間取り図・電話・のぼり） | 問い合わせ、買付、契約 |
| `desk` | 自宅の机（電卓・ノート・スタンド・コーヒー） | 計算する、考える、夜に悩む |
| `bank` | 銀行の窓口 | 融資を断られる（× を重ねる） |
| `bankbook` | 通帳のアップ（入金の行が増える） | 家賃が振り込まれる |
| `site` | 工事中（脚立・ペンキ缶・職人の道具・養生） | 直している最中、見積り |
| `night` | 夜の街（残業帰り・ビルの明かり・月） | 会社員の現実、「このままでいいのか」 |
| `sky` | 空と雲だけ（夢・未来・まとめ） | 1,000 万円の未来図、締め |
| `blank` | 無地（クリーム地） | 小道具だけ見せたいとき |

`time` と `weather` は背景に色味と雨・雲を重ねる（night は星と窓明かり）。

## 3. キャラの配置 `at` とポーズ `act`、表情 `face`

- `at`: `left` / `center` / `right` / `offleft`（画面外左から歩いて入り、`left` の位置で止まる。`act: walk` と組む）/ `offright`（同じく右から入って `right` で止まる）。または `x: 0〜100`（％）
- `act`（8 種・固定）: `stand`（立つ）/ `walk`（歩く。足と体が上下）/ `point`（指さす。向きは中央へ）/ `think`（あごに手・頭上に…）/ `cheer`（両手を上げる）/ `sit`（机に座る。desk / office で使う）/ `shock`（のけぞる・汗）/ `bow`（おじぎ）
- `face`: `normal` / `happy` / `surprised` / `doubt` / `calm` / `fire`（既存の 6 種）
- キャラは 2 人まで。1 人のときは `center` 推奨。

## 4. 小道具 `kind`（固定）

| kind | 何が出るか | 使う項目 |
|---|---|---|
| `headline` | 画面上部中央の大テロップ（オレンジ太字、白フチ） | `text` |
| `price` | 値札（白い札＋ひも、金額を大きく） | `text`, `at` |
| `sign` | 看板・立て札（「売地」「再建築不可」など） | `text`, `at` |
| `bubble` | 吹き出し（キャラの頭上。短い言葉） | `text`, `who` |
| `arrow` | 太い矢印とラベル | `text`, `dir`(up/down/right/left), `at` |
| `calendar` | 日めくり（「4か月」など） | `text`, `at` |
| `stamp` | ハンコ風（「空室」「契約」「満室」。赤丸） | `text`, `at` |
| `coins` | 金貨の山（count 枚） | `count`, `at` |
| `money` | お札が飛ぶ（金額ラベル） | `text`, `at` |
| `cross` | 大きな赤い × | `at` |
| `check` | 大きな緑の ✓ | `at` |
| `sweat` / `exclaim` / `question` / `heart` / `zzz` / `star` | キャラの頭上の記号（汗・！・？・♥・zzz・☆） | `who` |
| `photo` | 実物写真をポラロイド枠で（台本からの相対パス。無ければ枠だけ） | `image`, `caption`, `at` |
| `counter` | 転がる数字（小さめ）。`value`, `unit`, `label` | `value`, `unit`, `label`, `at` |

`at` 省略時は center。`step` でその小道具が出る段階を指定。出るときは pop（弾む）で入る。

## 5. 音（統合部が自動で付ける。台本で上書き可）

- 背景に応じた環境音を小さく敷く: street / house_* / site → 鳥と風、night → 虫、rain → 雨、room / office / desk / bank → 静かな室内
- 自動の効果音: `walk` → 足音、`office` の最初 → ドア、`bankbook` → レジ（お金）、`site` → とんかち、`stamp` → ハンコ、`money`/`coins` → コイン、`cross` → ずっこけ、`check` → ピン、`shock` → びっくり
- 台本で `sfx: [door, step]` と書けば、場面の頭にその順で鳴らす。`ambience: false` で環境音を止める

## 6. 映像クリップ（layout: clip）― AI 生成動画や実写を差し込む

参考動画のように画像生成 AI（Higgsfield など）で作った数秒のクリップや、スマホで撮った実写を入れる口。

```yaml
- id: clip1
  layout: clip
  file: clips/house_walk.mp4     # 台本からの相対パス。無ければ枠だけの画になり、警告を出す
  fit: cover                     # cover / contain
  headline: "これが50万円の家"      # 任意
  lines: [...]
```

台詞の長さに合わせて再生し、足りなければ最後のコマで止める。音声はクリップの音を使わない（ナレーションと BGM のみ）。

## 7. SNS ブロック（台本の末尾に書く。`make_posts.py` が文面ファイルにする）

```yaml
sns:
  x_thread:          # X のスレッド 5〜7 投稿。1 投稿 全角 140 字以内。URL は最後だけ
    - "…"
  x_single:          # 単発投稿 3 本（公開日・翌日・3 日後）
    - "…"
  threads:           # Threads 用 1〜2 本（500 字以内、最後は答えやすい問いで終える）
    - "…"
  note_outline:      # note 記事の骨子
    title: "…"
    free: ["見出し", "…"]      # 無料で読める部分
    paid: ["見出し", "…"]      # 有料ライン以降
    price: 500
  community: "…"     # YouTube コミュニティ投稿（公開前日）
  pinned_comment: "…" # 固定コメント（note の URL を含める）
```

## 8. 守ること（既存の線はそのまま）

- 「簡単」「誰でも」「確実」「必ず」「不労所得」を使わない。数字は丸めた実数で、★ を台詞に入れない。
- 社名・物件の住所・外観が特定できる写真は出さない（docs/07）。
- VOICEVOX のクレジットは説明欄に自動で入る。
