# 09 キャラクター設定 ― ユイさん と ソウタ

> **2026-10-17 方針（最優先）**: 本人は「50万円の戸建てを1戸ずつ買って積み上げる」投資を実際にはしていない（別のやり方で成果を出している）。
> 動画・SNS の物件・数字・失敗談は、**本人の体験ではなく「こういう投資のやり方もある」というモデルケース（説明のための例）**として語る。
> 解説役のユイさんは「モデルケースを案内する大家キャラ」で、本人とイコールではない。「私が買った」「私の家」「私が損した」「私の場合」と言い切らない。

> **2026-10-17 v7 でキャラを交代**（本人の指示「最も収益に向くキャラに」）。亀のコツさん・たぬきのぽん太から、人型のオリジナル 2 人へ。
> 選んだ理由: 表情が大きく出せてサムネで目を引く／人の顔は視聴者が感情を読み取りやすい／**自分で権利を持つオリジナル**なので許諾が要らず、
> 法人で使っても問題が出にくい／既存の合成音声キャラ（ずんだもん等）の見た目を使う「量産型」の動画に見えにくい
> （2025-07 以降、YouTube の「量産型のコンテンツ」で収益化停止の報告が多い。docs/15 §2）。
> 旧キャラ（コツさん・ぽん太）の絵は `characters.py` に残してあり、古い台本（S001 など）はそのまま作れる。

チャンネル「小規模な大家」の原作キャラクター。絵は `pipeline/characters.py` の SVG（権利は自分にある）。
声は VOICEVOX（商用可）。説明欄に「VOICEVOX:九州そら」「VOICEVOX:ずんだもん」のクレジットを入れる（publish.md に自動で出る）。
VOICEVOX のキャラクターの絵（ずんだもん等）は使わない。声だけ借りる。

## ユイさん（解説役。大家のお姉さん。本人とイコールではない）

- 姿: 20 代後半の女性。黒〜こげ茶のボブ、細いメガネ、白いブラウスに紺のジャケット、首に金色の鍵のネックレス（大家の印）。
- 立場: 不動産の仕入れと販売を仕事にしている大家。動画の物件・数字は「こういうやり方もある」というモデルケースとして案内する。自分の体験として「私が買った」とは言わない。
- 性格: 落ち着いていて、数字で話す。うまくいった話より、うまくいかなかった話を先にする。ソウタの皮算用を、費用と失敗で現実に戻す。
- 声: 九州そら。台本の `st:` は感情の名前で書けばよい（台本の `speakers.答.style_map` で声のスタイルに読み替える）。
  - 喜び → あまあま／熱血 → ツンツン（言い切り）／しっとり・かなしみ → ノーマル／囁き → ささやき
- 名乗り（固定文）: 「不動産の仕入れと販売を仕事にしている大家、ユイです」
- 口癖: 「数字は、買値、直し、家賃の順に見ます」「この例で言うと」「簡単ではありません。ただ…」
- 表情: normal（説明）、happy（数字が出た）、fire（言い切り）、calm（失敗談）、surprised（驚かされたとき）、doubt（念を押す）

## ソウタ（聞き役。新人会社員。視聴者の役）

- 姿: 20 代前半の男性。明るい茶髪の短髪、紺のスーツ、青いネクタイ、大きな目。
- 性格: 前のめり。利回りを見るとすぐ「すごい」と言う（皮算用）。でも疑うときはちゃんと疑う。視聴者が思うことを先に言う。
- 声: ずんだもん（声だけ。見た目・名前は使わない）。驚きは「あまあま」、疑いは「ツンツン」、しょんぼりは「なみだめ」、独り言は「ささやき」「ヒソヒソ」。
- 口癖: 「えっ、50万円で家！？」「それ、何年で戻るんですか？」「簡単、ではないですよね？」
- 表情: surprised（数字に驚く）、happy（皮算用で喜ぶ）、doubt（疑う）、calm（納得）

## 2 人の掛け合いの型（1 本に 3 回以上）

1. ユイさんが数字を出す → ソウタが皮算用で盛り上がる → ユイさんが費用（諸費用・管理費・修繕）と失敗で現実に戻す。
2. ソウタが「本当に？」と疑う → ユイさんがモデルケース（相場に沿った丸めた数字）で答える。
3. ソウタが「どうやって見つけるんですか？」→ ユイさんが「探し方・買い方・業者から紹介してもらうやり方は note に」（**送客はここ**。ポータルサイトを見ようとは言わない）。

## 画面での出し方

- 画面下の左にソウタ、右にユイさん。話していない側は薄く、3.7 秒ごとにまばたき。話している側は明るくなり、口が開閉し、台詞の `face:` の表情になる。
- 冒頭の自己紹介（`title` に `cast: true`）で 2 人を大きく出し、名前とひと言を添える。
- サムネはユイさん（既定）。驚きの回はソウタの surprised も使える（台本の `thumbnail.char`・`face`）。

## 台本での書き方

```yaml
speakers:
  聞: {speaker: "ずんだもん", style: "ノーマル", name: "ソウタ", color: "#2F80ED", char: "ソウタ"}
  答: {speaker: "九州そら", style: "ノーマル", name: "ユイさん", color: "#FF7A1A", char: "ユイさん",
       style_map: {喜び: あまあま, 熱血: ツンツン, しっとり: ノーマル, かなしみ: ノーマル, 不機嫌: ツンツン, 囁き: ささやき}}
lines:
  - {sp: 聞, text: "えっ、50万円で家！？", st: "あまあま", face: surprised}
scenes:
  - id: x
    layout: scene
    chars:
      - {who: ソウタ, at: left, act: stand, face: normal}
      - {who: ユイさん, at: right, act: point, face: normal}
```
`face` を省くと、`st`（喜び→happy、熱血→fire、しっとり→calm、ツンツン→doubt）と文末（！？→surprised、！→happy）から推定する。

## 使ってはいけないこと

- VOICEVOX のキャラクター（ずんだもん・九州そら等）のイラストや名前を、画面上のキャラ名として出さない（声のクレジットのみ）。
- ユイさん・ソウタに実在の人物・会社を連想させる設定を足さない。本人の会社名・物件を言わせない。

## ポーズ一覧（`act`。物語シーン docs/12 で使う）

`characters.py` の `yui(expr, mouth_open, blink, act="stand", facing="right")` / `souta(...)`。8 種は旧キャラと同じ名前。

| act | 使いどころ |
|---|---|
| `stand` | 既定 |
| `walk` | 物件を探して歩く、画面外から入る |
| `point` | 「あれが 50 万円の家」 |
| `think` | 計算する、悩む |
| `cheer` | 数字に喜ぶ、入居が決まる |
| `sit` | desk / office / bank（机・カウンターの奥に座る） |
| `shock` | 見積りが膨らんだ、融資を断られた |
| `bow` | お礼、締め |

- 見本: `python pipeline/characters.py out_dir` の `sheet.html`、または `python pipeline/scenes.py preview out_dir` の `sheet_poses.png`。
