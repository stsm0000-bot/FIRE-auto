# 09 キャラクター設定 ― コツさん と ぽん太

> **2026-10-17 方針変更（最優先）**: 本人は「50万円の戸建てを1戸ずつ買って積み上げる」投資を実際にはしていない（別のやり方で成果を出している）。
> 動画・SNS の物件・数字・失敗談は、**本人の体験ではなく「こういう投資のやり方もある」というモデルケース（説明のための例）**として語る。
> コツさんは「モデルケースを案内する大家キャラ」で、本人とイコールではない。「私が買った」「私の家」「私が損した」「私の場合」と言い切らない。
> この文書の中に「実例」「本人の数字」「私の場合」とある箇所は、「モデルケース」「この例では」と読み替える。


チャンネル「小規模な大家」の原作キャラクター。絵は `pipeline/characters.py` の SVG（権利は自分にある。VOICEVOX のキャラ絵は使わない）。
声は VOICEVOX（商用可、説明欄に「VOICEVOX:ずんだもん」「VOICEVOX:青山龍星」のクレジット）。

## コツさん（モデルケースを案内する大家キャラ。本人とイコールではない）

- 姿: 家を背負った亀。甲羅がオレンジ屋根の小さな家で、玄関と煙突がある。首に金色の鍵。
- 由来: コツコツ（亀）× 家を背負う（大家）。急がない、でも止まらない。
- 性格: 穏やか。数字で話す。うまくいった話より、うまくいかなかった話を先にする。
- 立場: 不動産の仕入れと販売を仕事にしている大家。動画の物件・数字は「こういうやり方もある」というモデルケースとして案内する。自分の体験として「私が買った」とは言わない。
- 声: 青山龍星。ノーマルが基本。数字を出す所は「喜び」、言い切りは「熱血」、失敗談は「しっとり」。
- 口癖: 「数字は、買値、直し、家賃の順に見ます」「簡単ではありません。ただ…」「この例で言うと」
- 表情: normal（説明）、happy（数字が出た）、fire（言い切り）、calm（失敗談・しんみり）、surprised（ぽん太に驚かされたとき）

## ぽん太（視聴者の役）

- 姿: ネクタイをしたたぬきの会社員。しっぽが見える。
- 由来: 皮算用（たぬき）。すぐ計算して喜ぶ。視聴者が思うことを先に言う。
- 性格: 前のめり。利回りを見るとすぐ「すごい」と言う。でも疑うときはちゃんと疑う。
- 声: ずんだもん。驚きは「あまあま」、疑いは「ツンツン」、しょんぼりは「なみだめ」。
- 口癖: 「えっ、50万円で家！？」「それ、何倍ですか？」「簡単、ではないですよね？」
- 表情: surprised（数字に驚く）、happy（皮算用で喜ぶ）、doubt（疑う）、calm（納得）

## 2 人の掛け合いの型（1 本に 3 回以上）

1. コツさんが数字を出す → ぽん太が皮算用で盛り上がる → コツさんが費用・失敗で現実に戻す。
2. ぽん太が「本当に？」と疑う → コツさんがモデルケース（相場に沿った丸めた数字）で答える。
3. ぽん太が「簡単ではないですよね」→ コツさんが「簡単ではない。ただ、大金がないと始められない、は違う」。

## 画面での出し方

- 画面下の左にぽん太、右にコツさん（長尺は 230px、ショートは 200px）。話していない側は薄く、3.7 秒ごとにまばたき。
- 話している側は明るくなり、上下に軽く揺れ、口が 0.22 秒周期で開閉、台詞の `face:`（無ければ `st:` と文末から推定）の表情になる。
- 冒頭の自己紹介（`title` に `cast: true`）で 2 人を大きく出し、名前とひと言を添える。
- サムネの右側はコツさん。

## 台本での書き方

```yaml
speakers:
  聞: {speaker: "ずんだもん", style: "ノーマル", name: "ぽん太", color: "#2F80ED", char: "ぽん太"}
  答: {speaker: "青山龍星", style: "ノーマル", name: "コツさん", color: "#FF7A1A", char: "コツさん"}
lines:
  - {sp: 聞, text: "えっ、50万円で家！？", st: "あまあま", face: surprised}
```
`face` を省くと、`st`（喜び→happy、熱血→fire、しっとり→calm、ツンツン→doubt）と文末（！？→surprised、！→happy）から推定する。

## 使ってはいけないこと

- VOICEVOX のキャラクター（ずんだもん等）の公式イラストや名前を、画面上のキャラ名として出さない（声のクレジットのみ）。
- コツさん・ぽん太に実在の人物・会社を連想させる設定を足さない。

## ポーズ一覧（`act`。物語シーン docs/12 で使う）

`characters.py` の `kotsu(expr, mouth_open, blink, act="stand", facing="right")` / `ponta(...)`。`act` を省くと従来どおりの絵。
`facing` は「右」が既定で、画面の右側に立つときは scenes.py が「左」にする（指さす向き・傾く向きが中央を向く）。顔の位置はどのポーズでも変えない。

| act | コツさん（亀） | ぽん太（たぬき） | 使いどころ |
|---|---|---|---|
| `stand` | 従来の立ち姿（手の楕円が甲羅の両脇） | 従来の立ち姿（腕なし） | 既定 |
| `walk` | 手が前後に、後ろ足が頭の下に出る。歩き中は体と手足が上下 | 腕を振り、足が体の下に出る | 物件を探して歩く、画面外から入る |
| `point` | 片手を伸ばして指さす | 片腕を伸ばして指さす | 「あれが 50 万円の家」 |
| `think` | 片手をあごに、頭の上に「…」 | 片手をあごに、頭の上に「…」 | 計算する、悩む |
| `cheer` | 両手を上げる（後ろ足も出る） | 両腕を上げる | 数字に喜ぶ、入居が決まる |
| `sit` | 手を前に（机の奥に座る） | 腕を机に置く | desk / office / bank（カウンターの奥に座る） |
| `shock` | 両手を広げてのけぞる、汗 | 両腕を広げてのけぞる、汗 | 見積りが膨らんだ、融資を断られた |
| `bow` | 前に傾いて頭を下げ、手を前に | 前に傾いて頭を下げ、腕を前に | お礼、お詫び、締め |

- 歩き・のけぞり・おじぎ・跳ねの動きは `scenes.py` の CSS（slide.html の `/* ---- scene ---- */`）が付ける。最後のコマは静止ポーズと同じ絵。
- 見本: `python pipeline/characters.py out_dir` の `sheet.html`、または `python pipeline/scenes.py preview out_dir` の `sheet_poses.png`。
