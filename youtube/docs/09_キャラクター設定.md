# 09 キャラクター設定 ― コツさん と ぽん太

チャンネル「小規模な大家」の原作キャラクター。絵は `pipeline/characters.py` の SVG（権利は自分にある。VOICEVOX のキャラ絵は使わない）。
声は VOICEVOX（商用可、説明欄に「VOICEVOX:ずんだもん」「VOICEVOX:青山龍星」のクレジット）。

## コツさん（大家本人の役）

- 姿: 家を背負った亀。甲羅がオレンジ屋根の小さな家で、玄関と煙突がある。首に金色の鍵。
- 由来: コツコツ（亀）× 家を背負う（大家）。急がない、でも止まらない。
- 性格: 穏やか。数字で話す。うまくいった話より、うまくいかなかった話を先にする。
- 立場: 不動産の仕入れと販売の仕事をしながら、自分でも小さい物件を買っている（冒頭の固定文）。
- 声: 青山龍星。ノーマルが基本。数字を出す所は「喜び」、言い切りは「熱血」、失敗談は「しっとり」。
- 口癖: 「数字は、買値、直し、家賃の順に見ます」「簡単ではありません。ただ…」「私の場合を丸めると」
- 表情: normal（説明）、happy（数字が出た）、fire（言い切り）、calm（失敗談・しんみり）、surprised（ぽん太に驚かされたとき）

## ぽん太（視聴者の役）

- 姿: ネクタイをしたたぬきの会社員。しっぽが見える。
- 由来: 皮算用（たぬき）。すぐ計算して喜ぶ。視聴者が思うことを先に言う。
- 性格: 前のめり。利回りを見るとすぐ「すごい」と言う。でも疑うときはちゃんと疑う。
- 声: ずんだもん。驚きは「あまあま」、疑いは「ツンツン」、しょんぼりは「なみだめ」。
- 口癖: 「えっ、50万円で家！？」「それ、何倍ですか？」「簡単、ではないですよね？」
- 表情: surprised（数字に驚く）、happy（皮算用で喜ぶ）、doubt（疑う）、calm（納得）

## 2 人の掛け合いの型（1 本に 3 回以上）

1. コツさんが数字を出す → ぽん太が皮算用で盛り上がる → コツさんが費用・失敗で現実に戻す。
2. ぽん太が「本当に？」と疑う → コツさんが実例（丸めた数字）で答える。
3. ぽん太が「簡単ではないですよね」→ コツさんが「簡単ではない。ただ、大金がないと始められない、は違う」。

## 画面での出し方

- 画面下の左にぽん太、右にコツさん（長尺は 230px、ショートは 200px）。話していない側は薄く、3.7 秒ごとにまばたき。
- 話している側は明るくなり、上下に軽く揺れ、口が 0.22 秒周期で開閉、台詞の `face:`（無ければ `st:` と文末から推定）の表情になる。
- 冒頭の自己紹介（`title` に `cast: true`）で 2 人を大きく出し、名前とひと言を添える。
- サムネの右側はコツさん。

## 台本での書き方

```yaml
speakers:
  聞: {speaker: "ずんだもん", style: "ノーマル", name: "ぽん太", color: "#2F80ED", char: "ぽん太"}
  答: {speaker: "青山龍星", style: "ノーマル", name: "コツさん", color: "#FF7A1A", char: "コツさん"}
lines:
  - {sp: 聞, text: "えっ、50万円で家！？", st: "あまあま", face: surprised}
```
`face` を省くと、`st`（喜び→happy、熱血→fire、しっとり→calm、ツンツン→doubt）と文末（！？→surprised、！→happy）から推定する。

## 使ってはいけないこと

- VOICEVOX のキャラクター（ずんだもん等）の公式イラストや名前を、画面上のキャラ名として出さない（声のクレジットのみ）。
- コツさん・ぽん太に実在の人物・会社を連想させる設定を足さない。
