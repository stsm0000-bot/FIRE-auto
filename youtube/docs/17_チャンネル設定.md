## 1. いまのチャンネルページの直す所（2026-10-18 の画面から）

| 場所 | いま | 直す理由 | 直し方 |
|---|---|---|---|
| バナー | 「最初の1件までの段取りを、架空の例で」＋チェック欄の絵 | 最初の企画（資料請求の段取り）のまま。動画の中身（安い戸建ての数字）とずれている | §2 の `banner.png` に差し替え |
| アイコン | 赤丸に「大家」 | 動画・サムネのキャラ（ユイさん）と結び付かない。小さく出ると文字が読めない | §2 の `icon.png`（ユイさんの顔） |
| 説明文 | 「まだ1件も物件を持っていない会社員が、最初の1件までの段取りを…」 | 同じく古い企画のまま。検索や「さらに表示」で最初に見える 1〜2 行に、何が分かるかが無い | §3 の文面に差し替え |
| リンク | note ＋ 他 2 件 | note が先頭なのは良い。表示名を「何が置いてあるか」にすると押される | §3.2 |
| ホーム画面 | 予告編・おすすめ動画・並びが未設定 | 初めて来た人に何のチャンネルか伝わらない | §4（予告編は `T001`） |
| 透かし | なし | 動画の右下から登録できるようにする | §2 の `watermark.png` |
| コミュニティ | 「コミュニティを有効にする」が出ている | 投稿（クイズ）は今の画面からもう出せる。視聴者どうしが書き込む「コミュニティ」は荒れ対策が要るので、登録者 1,000 人を超えてから | 今は押さない |
| 公開済みの動画 | 以前のショート（非公開 4 本） | 企画が変わったので、今の並びに混ぜない | 非公開のまま。002 と S002〜S004 から公開を始める |

## 4. ホーム画面（Studio → カスタマイズ → レイアウト）

| 枠 | 入れるもの |
|---|---|
| 登録していない人向けのチャンネル予告編 | **T001 チャンネル紹介（38 秒）**。`python pipeline/make_all.py scripts/T001_チャンネル紹介.yaml` で作り、限定公開か公開でアップロードしてから選ぶ |
| 登録している人向けのおすすめ動画 | 最新の長尺（今は 002） |

| セクション 2 | ショート |
| セクション 3 | 人気の動画（本数が 5 本を超えてから） |

再生リスト（Studio → コンテンツ → 再生リスト → 新しい再生リスト）:

| 名前 | 説明 | 入れる動画 |
|---|---|---|
| 1戸目の数字（モデルケース） | 安い戸建てを直して貸すまでの数字を、買値から手残りまで順に。数字は説明のためのモデルケースです。 | 002、003… の長尺 |

動画の説明欄と固定コメントの再生リスト URL（`{{PLAYLIST_URL}}`）は「1戸目の数字」の URL。決まったら台本の `playlist_url:` に書いて `make_all.py` を作り直す。

## 6. 毎回の動画で守る設定（アップロードのたび。docs/16 §7）

- AI で作ったリアルな写真を使った回は「改変または合成コンテンツ」に「はい」。
- 終了画面: 「次の動画」＋「登録」。カード: 中盤の note 送客の所に「1戸目の数字」の再生リスト。
