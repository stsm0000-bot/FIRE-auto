## 1. 最初の 1 回（環境を整える）

1. リポジトリを取り込む
   ```bat
   cd C:\Users\stsm0\Desktop
   git clone https://github.com/stsm0000-bot/FIRE-auto.git
   cd FIRE-auto
   git checkout claude/fervent-edison-ffigc4
   ```
2. `pip install -r youtube\pipeline\requirements.txt`
3. ffmpeg（gyan.dev の `ffmpeg-release-full`）を PATH に。
4. 動きを使う場合: `cd youtube\pipeline` → `npm init -y` → `npm i playwright`。実行時に `set PW_CHANNEL=chrome`。
   node を入れない場合は `set MOTION=0` で静止画モード（Chrome のヘッドレスで撮る。動きはなし）。
5. VOICEVOX を起動。`http://127.0.0.1:50021/speakers` で id を確認。
6. BGM を `youtube\pipeline\assets\bgm.mp3` に。

## 2. 1 本目を作る


- `out\002\002.mp4` を再生。QA が「合格」であること。
- 直すのは台本（YAML）だけ。同じコマンドをもう一度（変わった所だけ作り直す）。
- 確認の観点: 音量が他の動画と同じか／冒頭 20 秒に数字が出ているか／★の数字が実態に合っているか／読めない文字がないか／無音が 1 秒を超えていないか。

## 3. 2 本目以降の分担

- **クラウド**: 台本を書く。`docs/05` の順（003 → 004 → …）に、長尺 1 本＋ショート 2 本の YAML を書き、スタブで尺と画を確認してコミット。
- **ローカル**: pull → build → ★確認 → 写真 → アップロード（予約投稿）→ 終了画面とカード。

## 4. 困ったとき

| 症状 | 見る所 |
|---|---|
| `Chrome/Edge が見つかりません` | 環境変数 `CHROME_PATH` に chrome.exe の場所 |
| 動きが出ない（全部静止画） | `node -e "require('playwright')"` が通るか。`MOTION=0` になっていないか |
| Playwright がブラウザを落とそうとする | `set PW_CHANNEL=chrome` で手元の Chrome を使う |
| 字幕が出ない・豆腐になる | ffmpeg が libass 入りか／フォント名（台本の `font:` に `Meiryo` など） |
| 音声が作れない | VOICEVOX が起動しているか、`VOICEVOX_URL`、話者 id |
| 音が小さい・大きい | QA のラウドネス値。-14 から外れていたら `--bgm-db` か VOICEVOX の音量 |
| 長尺の尺が足りない | 聞き手の疑問と例文・失敗談を足す（docs/01 §2、docs/07 §4） |
