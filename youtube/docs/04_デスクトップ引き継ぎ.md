# 04 デスクトップ引き継ぎ ― ここからの進め方

クラウド側（この文書を含む一式）でやったこと:
現状診断、設計図、台本の書き方、制作パイプラインの実装とスタブ音声での検証、サンプル台本 2 本。
デスクトップ側でやること: VOICEVOX をつないで本番の音声で 1 本作り、見て、直して、公開する。

## 1. 最初の 1 回（環境を整える）

1. リポジトリを取り込む
   ```bat
   cd C:\Users\stsm0\Desktop
   git clone https://github.com/stsm0000-bot/FIRE-auto.git
   cd FIRE-auto
   git checkout claude/fervent-edison-ffigc4
   ```
   （この PR を main に取り込んだあとは main で可）
2. 依存を入れる: `pip install -r youtube\pipeline\requirements.txt`
3. ffmpeg を入れる（gyan.dev の `ffmpeg-release-full`、PATH に通す）。`ffmpeg -filters | findstr subtitles` で `subtitles` が出れば可。
4. VOICEVOX を起動し、ブラウザで `http://127.0.0.1:50021/speakers` を開き、冥鳴ひまり・雀松朱司の `id` を控える。
   既定（14, 52）と違えば台本の `speakers:` に書く。
5. BGM を `youtube\pipeline\assets\bgm.mp3` に置く（YouTube オーディオライブラリ → 帰属表示不要 → 落ち着いたもの 1 曲）。

## 2. 1 本目を作る

```bat
cd C:\Users\stsm0\Desktop\FIRE-auto\youtube
python pipeline\make_video.py build scripts\001_資料が届かない人.yaml --out out\001
```

- `out\001\001.mp4` を再生して確認。QA が「合格」であること。
- 直すのは台本（YAML）だけ。直したら同じコマンドをもう一度（変わった所だけ作り直す）。
- 確認の観点: 音量が他の動画と同じか／冒頭 20 秒で結論を言っているか／読めない文字がないか／無音が 1 秒を超えていないか。

## 3. デスクトップの Claude Code に貼る指示（そのまま貼る）

```
youtube/docs/00〜05 を読んでから作業してください。
目的: youtube/scripts/001_資料が届かない人.yaml から本番の動画を作り、公開できる状態にする。
手順:
1. VOICEVOX が http://127.0.0.1:50021 で動いているか確認し、/speakers で 冥鳴ひまり と 雀松朱司 の id を確認。既定(14,52)と違えば台本の speakers を直す。
2. python youtube/pipeline/make_video.py build youtube/scripts/001_資料が届かない人.yaml --out youtube/out/001 を実行。
3. 失敗したら原因を直す（Windows のパス、フォント名、ffmpeg の有無が多い）。make_video.py を直した場合は、その差分を説明する。
4. QA 合格まで台本を調整。尺が 4 分未満なら、docs/01 の構成に沿って章の中身を足す（新しい話題を足すのではなく、例文と聞き手の疑問を足す）。
5. out/001/publish.md の説明欄の note URL を実際の記事に差し替える。
6. 出来たら、次は scripts/S001_最初の一通は4つ.yaml をショートとして同様に作る。
制約: docs/01 の仕様から外れる変更はしない。数字や例は架空のまま。個別相談を誘う文言は入れない。
```

## 4. 2 本目以降の分担

- **クラウド（トークンに余裕がある側）**: 台本を書く。`docs/05_シリーズ企画.md` の順に、note の記事 1 本につき長尺 1 本＋ショート 2 本の YAML を書いてコミットする。
  スタブ音声で尺と画を確認してから渡す。
- **デスクトップ**: pull して build、本番音声で確認、YouTube Studio にアップロード（予約投稿）、終了画面とカードを設定。

## 5. 困ったとき

| 症状 | 見る所 |
|---|---|
| `Chrome/Edge が見つかりません` | 環境変数 `CHROME_PATH` に chrome.exe の場所 |
| 字幕が出ない・豆腐になる | ffmpeg が libass 入りか／フォント名（台本の `font:` に `Meiryo` など） |
| 音声が作れない | VOICEVOX が起動しているか、`VOICEVOX_URL`、話者 id |
| 音が小さい・大きい | QA のラウドネス値を見る。-14 から外れていたら BGM の音量（`--bgm-db`）か VOICEVOX の音量を調整 |
| 長尺の尺が足りない | 台本に聞き手の疑問と例文を足す（docs/01 §2） |
