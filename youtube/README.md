# youtube ― チャンネル「小規模な大家」の動画制作一式

| 場所 | 中身 |
|---|---|
| `docs/00_現状診断.md` | いまの動画とチャンネルの何が弱いか（計測値つき） |
| `docs/01_動画設計図.md` | 構成・画・音・字幕の仕様。台本の書き方 |
| `docs/02_制作パイプライン.md` | 台本 → 動画の仕組みと必要なもの |
| `docs/03_公開テンプレート.md` | タイトル・説明欄・サムネ・終了画面・運用 |
| `docs/04_デスクトップ引き継ぎ.md` | デスクトップで最初にやること、Claude Code に貼る指示 |
| `docs/05_シリーズ企画.md` | note の記事に対応させた動画の並び |
| `docs/06_参考チャンネル研究.md` | 伸びている不動産投資系の見せ方と、真似する要素 |
| `docs/07_実例シリーズの作り方.md` | 自分の物件を特定されずに数字で語る線引き、公開前の確認表 |
| `docs/08_事業計画.md` | 収益の見立て、収益化までの道筋、12 週の計画、見る数字 |
| `docs/09_キャラクター設定.md` | コツさん（亀の大家）とぽん太（たぬきの会社員）の設定・表情・掛け合いの型 |
| `docs/10_制作体制.md` | 部署の分け方（台本・演出・音響・キャラ・統合・品質・公開）と 1 本の流れ |
| `docs/11_品質レビュー.md` | 品質部の講評（採点と「必ず直す 5 つ」） |
| `docs/12_物語シーンの書き方.md` | 物語シーン（layout: scene）と映像クリップ（clip）、SNS ブロックの語彙。台本部・演出部・統合部の共通仕様 |
| `docs/13_伸びる動画の設計.md` | 再生と収益に効く作り（冒頭 30 秒・8 分以上・タイトルとサムネの型・題材 20・note 送客・繰り返し判定の回避・運用） |
| `docs/14_SNS戦略.md` | X・Threads・note・YouTube の役割分担、週間カレンダー、投稿テンプレ、X 収益化の現実、note の価格 |
| `docs/15_引き継ぎ書.md` | **デスクトップの Claude Code に渡す最新の引き継ぎ**（貼る指示・成果・★一覧・運用・次の 4 本） |
| `pipeline/scenes.py` | 物語シーンの背景 13 種・小道具・カメラ（SVG） |
| `pipeline/make_posts.py` | 台本の sns ブロックから X・Threads・note・説明欄・固定コメントの文面を生成（文字数・禁止語を検査） |
| `pipeline/make_video.py` | 台本（YAML）から mp4・サムネ・説明文を作る |
| `pipeline/audio_synth.py` | 効果音 18 種・環境音 5 種・BGM の自前合成（権利問題なし） |
| `pipeline/characters.py` | キャラクターの絵（SVG）。表情 6 種・ポーズ 8 種・口・まばたき |
| `pipeline/render_frames.js` | 動き（出現・数字が伸びる・戸建てが増える）を 1 コマずつ撮る（node + Playwright） |
| `scripts/` | 台本。`NNN_題名.yaml`（長尺）、`SNNN_題名.yaml`（ショート） |

台本は `002_50万円の戸建てから.yaml`（実例シリーズ・物語版 v4、約 9 分、物語シーン＋図解）が最新の見本。ショートは `S002`〜`S004`。
最初に読むのは `docs/15_引き継ぎ書.md`。

最短の使い方:

```bat
pip install -r pipeline\requirements.txt
python pipeline\make_video.py build scripts\001_資料が届かない人.yaml --out out\001
```
