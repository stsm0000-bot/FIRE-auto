## 5. 毎回の動画の作り方（型）

`youtube/docs/16_動画1本の作り方.md` が手順の本体。`/make-video` でも同じ流れになる。

1. 題材とタイトル（Claude が 3 案、本人が選ぶ）
2. 台本（`scripts/_ひな形_長尺.yaml`・`_ひな形_ショート.yaml` をコピー。002 が完成見本）
3. 音声なしで試す（`--tts stub`）→ 尺・画の重なりを直す
4. ★の数字を本人が確かめる
5. 本番ビルド → `out\<番号>\納品\` にそろう → 字幕の時刻で投稿文の時刻を合わせる
6. 本人が見て OK → コミット・push
7. アップロードと予約、SNS（§4 の B〜F と同じ）

## 6. コマンド集（`C:\Users\stsm0\Desktop\FIRE-auto\youtube` で）

```bat
set PW_CHANNEL=chrome
rem 新しい動画: 音声なしで試す → 本番（VOICEVOX を起動しておく）
python pipeline\make_all.py scripts\003_題名.yaml --tts stub
python pipeline\make_all.py scripts\003_題名.yaml scripts\S005_題名.yaml scripts\S006_題名.yaml scripts\S007_題名.yaml

rem 今回の成果物を作り直す（★や写真を直したとき）→ out\<番号>\納品\
python pipeline\make_all.py scripts\002_50万円の戸建てから.yaml scripts\S002_50万円の戸建ての数字.yaml scripts\S003_見積りが60万円膨らんだ話.yaml scripts\S004_5千円欲張って4か月空室.yaml scripts\T001_チャンネル紹介.yaml

rem チャンネルのバナー・アイコン・透かし → channel\
python pipeline\make_channel_art.py

rem 投稿文だけ作り直す（URL を書いたとき）
python pipeline\make_posts.py scripts\002_50万円の戸建てから.yaml --out out\002\sns --publish out\002\publish.md --strict
```

ローカルで作り直すと、フォントや声の細かな差で尺が数秒ずれることがある。ずれたら `字幕の時刻.txt` を見て台本の `sns:` の時刻を直す。
